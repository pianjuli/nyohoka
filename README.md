# 🔨 Lokalist — Direktori Jasa Pertukangan

Direktori jasa pertukangan lokal berbasis web. Cari tukang, las, listrik, cat, plumbing, dan jasa bangunan lainnya dengan mudah.

## Fitur
- 🔍 Pencarian & filter berdasarkan kategori
- 📍 Tombol langsung ke Google Maps, WhatsApp, Telepon
- ⭐ Rating & ulasan
- 🗂️ Dashboard admin (tambah/edit/hapus)
- 💾 Data tersimpan otomatis di browser (localStorage)
- 📱 Responsif di semua perangkat

## Deploy ke GitHub Pages
Lihat panduan di bawah atau ikuti file `PANDUAN_DEPLOY.md`.

## Teknologi
- HTML, CSS, JavaScript murni (tanpa framework)
- Tabler Icons
- Google Fonts (Plus Jakarta Sans)
- localStorage untuk penyimpanan data
